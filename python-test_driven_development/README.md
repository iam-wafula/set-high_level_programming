# Python - Test Driven Development

This project is part of the SE 202 High Level Programming curriculum.

## Learning Objectives

- Write Python functions using Test-Driven Development (TDD)
- Write and run doctests
- Write unit tests using the unittest module
- Handle exceptions correctly
- Validate function arguments
- Write clean, documented Python code following PEP 8
