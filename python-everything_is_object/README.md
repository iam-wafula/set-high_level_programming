# Python - Everything is Object

This project is part of the SET High Level Programming curriculum.

## Learning Objectives

- Understand that everything in Python is an object.
- Learn object identity and mutability.
- Understand variable assignment and references.
- Compare `==` and `is`.
- Work with lists and tuples.
- Learn how Python handles memory and object creation.

## Files

This directory contains answers and Python scripts for the **Everything is Object** project.
