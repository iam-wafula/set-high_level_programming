# Python - Almost a Circle

## Description

This project is part of the **SE 202: High Level Programming I** curriculum.

The objective is to apply the principles of:

- Object-Oriented Programming (OOP)
- Inheritance
- Encapsulation
- Serialization and Deserialization using JSON
- Unit Testing
- File handling
- Python packages and modules

The project implements three classes:

- Base
- Rectangle
- Square

The `Base` class manages object IDs and JSON serialization. `Rectangle` and `Square` inherit from `Base` and provide geometry-related functionality.
