# Python - Data Structures: Lists, Tuples

This project is part of the **SE 202: High Level Programming I** curriculum.

## Description

This project introduces Python data structures, focusing on lists and tuples. It covers creating, modifying, accessing, and manipulating lists and tuples, as well as writing functions that work with them.

## Learning Objectives

- Print elements in a list
- Access list elements safely
- Replace and delete list elements
- Work with copies of lists
- Manipulate strings
- Print matrices
- Perform operations on tuples
- Return multiple values from functions
- Find the maximum value in a list
- Check divisibility of list elements
- Swap variables in Python
