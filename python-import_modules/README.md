# Python - Import & Modules

This project is part of the **SE 202: High Level Programming I** curriculum.

## Project Objectives

The project covers:

- Importing functions from another Python file
- Importing variables
- Using command-line arguments (`sys.argv`)
- Creating executable Python scripts
- Working with Python modules
- Understanding the `__name__ == "__main__"` construct
- Basic arithmetic using imported functions

## Files

| File | Description |
|------|-------------|
| `0-add.py` | Imports a function and performs addition |
| `1-calculation.py` | Imports calculator functions and performs arithmetic |
| `2-args.py` | Prints the number and list of command-line arguments |
| `3-infinite_add.py` | Adds all command-line arguments |
| `4-hidden_discovery.py` | Lists names from a compiled Python module |
| `5-variable_load.py` | Imports and prints a variable |
| `100-my_calculator.py` | Command-line calculator |
| `101-easy_print.py` | Prints `#pythoniscool` without using `print` |
| `102-magic_calculation.py` | Recreates a function from Python bytecode |
| `103-fast_alphabet.py` | Prints the uppercase alphabet |

## Requirements

- Python 3.8+
- Ubuntu/Linux
- All files are executable
- PEP 8 (pycodestyle) compliant
