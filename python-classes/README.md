# Python - Classes and Objects

This project is part of the SE 202: High Level Programming I course.

## Description

This project introduces Object-Oriented Programming (OOP) in Python.

Topics covered include:

- Classes and objects
- Private attributes
- Properties and setters
- Methods
- Data validation
- String representation
- Operator overloading
- Linked lists

## Files

| File | Description |
|------|-------------|
| 0-square.py | Empty Square class |
| 1-square.py | Square class with private size |
| 2-square.py | Square class with size validation |
| 3-square.py | Square class with area method |
| 4-square.py | Square class with getter and setter |
| 5-square.py | Square class that prints a square |
| 6-square.py | Square class with position |
| 100-singly_linked_list.py | Singly linked list implementation |
| 101-square.py | Square instance printing |
| 102-square.py | Square comparison operators |
| 103-magic_class.py | MagicClass implementation from bytecode |

## Requirements

- Python 3
- No external modules except where specified
- Follow Python coding standards
