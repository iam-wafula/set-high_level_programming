# Python - More Data Structures

This project is part of the SE 202: High Level Programming I course.

## Description

This project focuses on learning and implementing more Python data structures, including:

- Lists
- Sets
- Dictionaries
- Lambda functions
- Map function
- Data manipulation techniques

## Requirements

- Python 3
- Ubuntu 20.04
- No external modules allowed
- All files must follow Python coding standards

## Files

| File | Description |
|------|-------------|
| 0-square_matrix_simple.py | Computes the square value of all integers in a matrix |
| 1-search_replace.py | Replaces elements in a list |
| 2-uniq_add.py | Adds unique integers in a list |
| 3-common_elements.py | Finds common elements between two sets |
| 4-only_diff_elements.py | Finds elements present in only one set |
| 5-number_keys.py | Returns the number of dictionary keys |
| 6-print_sorted_dictionary.py | Prints a dictionary sorted by keys |
| 7-update_dictionary.py | Updates or adds dictionary keys |
| 8-simple_delete.py | Deletes a dictionary key |
| 9-multiply_by_2.py | Multiplies dictionary values by 2 |
| 10-best_score.py | Finds the key with the highest value |
| 11-multiply_list_map.py | Multiplies list values using map |
| 12-roman_to_int.py | Converts Roman numerals to integers |
| 100-weight_average.py | Calculates weighted average |
| 101-square_matrix_map.py | Squares matrix values using map |
| 102-complex_delete.py | Deletes dictionary keys by value |
| 103-python.c | Prints information about Python objects |
