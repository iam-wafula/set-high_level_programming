# Python - More Classes

This project is part of the SE 202: High Level Programming I course.

The project focuses on object-oriented programming in Python, especially classes, objects, properties, methods, static methods, class methods, and object lifecycle.

## Tasks

- **0. Simple Rectangle** — Create an empty `Rectangle` class.
- **1. Real Definition of a Rectangle** — Add width and height properties with validation.
- **2. Area and Perimeter** — Calculate the area and perimeter of a rectangle.
- **3. String Representation** — Represent a rectangle using the `#` character.
- **4. Eval is Magic** — Add a representation that can recreate a rectangle using `eval()`.
- **5. Detect Instance Deletion** — Display a message when a rectangle is deleted.
- **6. How Many Instances** — Track the number of Rectangle instances.
- **7. Change Representation** — Allow the symbol used to display rectangles to be changed.
- **8. Compare Rectangles** — Compare rectangles based on their areas.
- **9. A Square is a Rectangle** — Create squares using a class method.
- **10. N Queens** — Solve the N Queens puzzle using backtracking.
